# Ground rules

- Same `requirements.md`, same stack, same model, same starting commit (`main`).
- Framework files live in the branch only; keep app code in `src/` (same layout in all branches) so diffs are comparable.
- Log time, tokens/cost and human interventions in `comparison.md`.
- No cross-pollination: do not copy code between branches mid-run.
- Plan changes happen on `main`, then get merged into each branch.
